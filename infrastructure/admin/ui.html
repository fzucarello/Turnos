Acceso y credenciales

La aplicación está protegida con Cloudflare Access, y comprueba adicionalmente la firma del token y el correo autorizado. Los secretos no se guardan en D1 ni se muestran en esta página.

Credenciales actuales

OSEP_USER · OSEP_PASS · GITHUB_TOKEN

Para sustituirlos de manera segura, abrí el dashboard de Cloudflare, elegí Workers & Pages → osep-scheduler → Settings → Variables and Secrets. Pegá el valor nuevo como Secret, sin copiarlo al repositorio ni al chat.

Abrir Cloudflare

Las credenciales no pueden recuperarse en texto claro. El recambio se hace en el almacén cifrado de Cloudflare, con control de acceso administrativo.
